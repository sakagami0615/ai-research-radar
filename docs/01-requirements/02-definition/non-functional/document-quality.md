# N-07 成果物と変更の品質

プロジェクトの成果物は日本語で作成する。取得した原文や識別子は原情報として保持する。実装・設定・設計・Skillなどの変更後は、軽微でもレビューを行い、完了条件に関わる指摘を解消する。

## 受入条件

- Claude CodeとCodexで共通の正本を利用する。
- 要件、設計、実装の状態に差がある場合は明示し、切替時に同期する。
- 作成者と異なる担当または視点でレビューし、修正と再確認を記録する。
- 再発条件が分かった場合、関係する手順・設計・テストに知見を残す。
- Agent手順を変えた場合は、可能な範囲で実機確認し、未確認の範囲を明示する。
- 使用するツール・パッケージはLTS最新版を選ぶ。既存のバージョン設定を変更する際は、互換性と設計への影響を確認する。
