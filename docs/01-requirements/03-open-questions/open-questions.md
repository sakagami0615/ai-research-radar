# 未決定事項

既存資料から決定できない条件を列挙する。今回の再編では値を創作せず、関連作業の着手に必要になった時点で利用者に確認する。

| ID | 未決定の内容 | 確定が必要になる場面 |
| --- | --- | --- |
| Q-01 | 誤検知・見落とし・確認時間など、継続運用の数値目標 | 品質改善の受入指標を追加・変更するとき |
| Q-02 | 日次実行の時間・費用・候補確認量の上限 | 定期実行の負荷とAgent確認範囲を最適化するとき |
| Q-03 | 保存期間・容量・バックアップ・復旧目標 | データ保持や削除の運用を実装するとき |
| Q-04 | 未実装の品質改善を実装する順序と対象範囲 | バックログから次の実装を選ぶとき |
| Q-05 | 週次・月次・年次レポートの利用場面と受入条件 | 日次MVPを超える拡張に着手するとき |

旧監査改善設計の固定標本・誤昇格ゼロなどの既存条件は [品質改善の受入](../../04-verification/audit-remediation-acceptance.md) に保持する。Q-01はそれらを撤回するものではない。
