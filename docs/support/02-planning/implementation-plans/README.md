# 実装計画

新しい実装計画はこのフォルダに置き、目的・対象要件ID・参照設計・作業と依存・検証・完了条件・レビュー範囲を記す。日本語で、変更単位ごとにファイルを分ける。

旧 `docs/superpowers/plans/2026-10-01-audit-remediation.md` はGit管理対象外で、このworktreeには存在しない。その内容を推測で再作成しない。品質改善の継続着手時に元計画を確認し、必要な確定情報をGit管理する本フォルダへ移すか、新たな計画を利用者と合意する。

計画を置いたことは実装着手や受入の完了を意味しない。[適用状況](../requirement-status.md)と [バックログ](../backlog.md) を対応づける。
