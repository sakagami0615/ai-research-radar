# 開発・運用支援

仕様・設計に基づいて実行・確認し、未達事項から次の作業へ進むための資料を置く。

1. [運用](01-operations/README.md)：セットアップ、日次・定期実行、結果確認、復旧、改善。
2. [計画・適用状況](02-planning/README.md)：対応状態、バックログ、将来対応、実装計画。
3. [参考調査](03-reference/README.md)：参考図とローカルのAPPENDIX。

要件・設計・検証方法の正本は [spec](../spec/README.md) を参照する。環境準備・自動テスト・Agent実機確認の手順は [テスト実行ガイド](01-operations/testing/README.md) にある。検証記録の新しい配置は別途整理し、現在の受入記録はspec配下に維持する。
