# テスト実行ガイド

AGENTS.mdにあったテスト実行時の注意事項を、Claude Code・Codex共通の手順としてまとめる。ここでは環境準備・実行・結果確認を扱い、テスト対象と合格条件の正本は [検証・受入](../../../spec/04-verification/README.md) とする。

## 読む順と対象手順

1. [環境準備](01-environment.md)：対象コード、Python環境、入力・出力先を確認する。すべてのテストで先に読む。
2. [自動テスト](02-automated-tests.md)：Pythonコードの変更確認、回帰確認を行う場合に読む。
3. [Agent実機確認](03-agent-smoke-tests.md)：Skill・プロンプト変更時、またはAgent経路を確認する場合に読む。
4. [HOT候補の前後比較](04-hot-candidate-comparison.md)：収集時に決まる判定(AI関連度・公式ブログの種別など)を変え、実データの過去日でHOT候補の変化を確かめる場合に読む。

Skill・プロンプトの変更は静的レビューだけでなく、可能であればAgentに読ませ、変更した手順の分岐・再試行・終了条件まで実機確認する。読み取り専用の参照確認と、CLI実行を伴う確認は別の範囲として扱う。

## 結果の扱い

対象コードを確認できない実行は合格としない。未実施・権限制約・入力不足などは、確認できなかった範囲と理由を明記する。自動テストの成功だけでAgent実機確認や全要件の受入が済んだとみなさない。

実施日時、コード版・dirty状態、作業ディレクトリ、Python／Agent、対象・入力、実行コマンド、終了コード、結果・ログへの参照、未検証事項を記録する。現時点の受入記録の置き場は [受入結果](../../../spec/04-verification/acceptance/results.md) を参照する。今回、新しい検証記録フォルダは作成しない。
