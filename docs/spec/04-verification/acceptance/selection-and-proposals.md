# 選抜・企画の受入

対象: F-03・F-04。条件の正本は [HOT要件](../../01-requirements/02-definition/functional/hot-selection.md)と [企画要件](../../01-requirements/02-definition/functional/article-ideation.md)。

1. 一次根拠を確認できる候補、取得不能候補、AI無関連候補を固定する。
2. 選抜入力を検証し、不正な型・ID・根拠条件・件数上限を拒否することを確認する。
3. 選抜0件・未実行・失敗の表示と記録を区別する。
4. 企画の必須品質項目、元HOTとの対応、追加根拠の役割、不正入力を確認する。
5. 別担当が根拠の内容と判断・企画の具体性を確認する。CLIの入力検証で内容確認を代用しない。
6. 品質改善の候補保存経路が接続された時点で、低い参考点や欠損だけで研究候補が落ちないことを確認する。

一括dailyの現行挙動は別結果として記録し、Agentによる品質判断済みとしない。
