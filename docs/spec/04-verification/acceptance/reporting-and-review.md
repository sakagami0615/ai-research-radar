# 表示・独立レビューの受入

対象: F-05・F-06。[レポート要件](../../01-requirements/02-definition/functional/reporting.md)と [レビュー要件](../../01-requirements/02-definition/functional/review.md)を参照。

1. 選抜あり・保留・未実行・失敗・過去3日データありを固定して日次表示と集約を確認する。
2. 概要・傾向・記事企画が日本語で出力され、未確認の内容を断定しないことを別担当が確認する。
3. 独立レビューの正常終了、起動失敗、重要指摘、初回を含む3回上限をAgent実機で確認する。
4. 指摘後の修正・再生成を確認し、未解消では警告と `needs_review` が残ることを確認する。
5. 品質改善のレビュー記録接続後は、対象変更時の古い承認、結果欠落、hash不一致が承認されないことを確認する。

レビュー記録モジュールの単体テストだけでSkillと本番経路の動作を確認済みにしない。
