# 利用者と利用場面

主な利用者はAIエンジニア。既存コンセプトの「動向把握と技術記事候補の判断」を次の利用場面に整理する。別の利用者像や新しい配信機能を追加するものではない。

| ID | 利用場面 | 得たい結果 |
| --- | --- | --- |
| UC-01 | 日次レポートを読む | 重要候補の内容・根拠・未確認事項を把握する |
| UC-02 | 記事・小規模実験を検討する | 問い・比較対象・確認方法を読み、採否を判断する |
| UC-03 | 定期調査の結果を確認する | 成果なし、取得失敗、未実行、品質未承認を見分ける |
| UC-04 | 失敗や修正要望から環境を改善する | 原因と影響を追い、必要な実装・設定・Skill・設計を更新する |

実行Agentと独立レビューAgentはシステム運用上の担当であり、レポートの利用者とは役割が異なる。[責任分担](../../02-architecture/workflows.md)を参照する。
