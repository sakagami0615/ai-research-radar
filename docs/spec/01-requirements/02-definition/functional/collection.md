# F-01 公開情報の収集

UC-01・UC-03に対応する。認証なしで取得可能な公開Sourceから、指定された期間に応じてAI関連情報と原データを取得・保存できること。

## 受入条件

- 対象Sourceと取得期間を指定でき、結果とSource単位の失敗を確認できる。
- Source固有の取得上限・RSS掲載範囲などの制約を示し、期間全体の網羅を保証したと扱わない。
- rawを保存し、再処理の材料を残す。
- 品質改善目標として、取得方式・期間基準・上限・部分失敗・打ち切りの可能性を診断情報として保存・表示する。未確認の残件数を創作しない。

対象はAgent経路・一括daily。既存Sourceの具体的な選択は [Adapter設計](../../../03-detailed-design/source-adapters/README.md)、品質改善の診断目標は [変更設計](../../../05-decisions/audit-remediation/collection-and-proposals.md) を参照。元の要求は旧コンセプトと旧監査改善設計の収集範囲に由来する。
