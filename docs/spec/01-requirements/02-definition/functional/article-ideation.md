# F-04 採否を判断できる記事企画

UC-02に対応する。選抜HOTから、人間が記事化や小規模実験の採否を判断できる企画を得られること。記事本文の自動執筆は対象外。

## 受入条件

- Agent経路では1HOTあたり0〜3案とし、数を埋めるための定型企画を採用しない。
- 問い、既存手段との差分、比較対象と版、測定方法、入力・環境、工数と前提、成功・中止条件を具体的に記す。
- 主張と根拠を対応させ、追加した比較対象のURLには役割を記す。
- 選抜HOTがあるのに企画を作らない場合は、理由を記録する。
- 保存時の型検証と、企画内容の品質レビューを分ける。

一括dailyの旧形式の定型企画は上記の品質受入を満たした証拠にはならない。[入力契約](../../../03-detailed-design/data-models/article-proposals.md)、[生成経路](../../../03-detailed-design/pipeline/ideation.md)を参照。
