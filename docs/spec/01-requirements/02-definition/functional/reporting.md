# F-05 日次レポートと構造化データ

UC-01〜UC-03に対応する。日次の確認に使えるレポートと、その根拠・判断に戻れる構造化データを保存すること。

## 受入条件

- 日次Markdownに選抜HOT、記事企画、実行結果、エラー、収集Source一覧を表示する。
- 当日の選抜に加え、直近3日の未掲載注目候補と新モデルリリースを既定の集約規則に従って表示する。
- Agent経路では概要とSourceごとの傾向を日本語で補い、確認できなかった情報を断定しない。
- 原文一覧は原文として扱い、概要・日本語成果物と区別する。
- 成果なし、未実行、保留、失敗を混同しない。品質改善目標として生成成功と品質承認を明示的に分ける。

両経路でレポートを生成するが、一括dailyはAgentによる概要・傾向を作成しない。[表示契約](../../../03-detailed-design/reporting/README.md)を参照。
