# N-05／N-06 機密管理と運用性

## N-05 機密情報の扱い

品質改善の実行情報に認証情報や環境変数の値を保存しない。公開設定と機密情報を区別する。受入では、記録される設定・URL等に機密値が残らないことを確認する。実行情報(provenance)の記録は未実装である(未結線だったモジュールはPR #33で削除済み。[既知課題](../../../../support/02-planning/known-gaps.md))。

## N-06 実行と診断

手動・cronから日次処理を実行でき、必要なPATH・実行ディレクトリ・ログ・同日排他を設定できること。終了コードだけで品質成功とせず、実行記録・レポート・エラーを確認できることを受入条件とする。

[定期実行](../../../../support/01-operations/scheduled-run.md)、[結果確認](../../../../support/01-operations/result-checks.md)を参照。費用・実行時間・保存容量の上限は今回確定しない。
